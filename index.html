Přihlášení správce

Stahovat může každý bez přihlášení. Token potřebuješ jen ty, kdo playlisty nahrává.

Jak token získat
  1. Na GitHubu otevři Settings → Developer settings → Personal access tokens → Fine-grained tokens a klepni na Generate new token.
  2. U Repository access zvol Only select repositories a vyber repozitář s touto stránkou.
  3. V Permissions → Repository permissions nastav Contents: Read and write.
  4. Token vygeneruj, zkopíruj (začíná github_pat_) a vlož sem. Zůstane uložený jen v tomto prohlížeči.
